# Security Policy

## Supported versions

Security guidance evolves as tools, platforms, and best practices change. Security fixes and corrections are applied to the latest version on the default branch.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Earlier snapshots | No |

## Reporting a vulnerability or unsafe guidance

Please **do not open a public issue** for a suspected vulnerability, exposed secret, unsafe command, misleading recommendation, or security-sensitive error in this repository.

Instead, report it privately through the repository owner's GitHub profile: [@txRandria](https://github.com/txRandria). Include, where possible:

- The affected skill and section
- A clear description of the risk or incorrect behavior
- Reproduction steps or a minimal example
- The impact and any suggested safer alternative

## What to expect

We aim to acknowledge reports within 7 days, assess reproducibility and impact, and provide an update on the planned resolution when possible. Confirmed issues will be corrected on the default branch and documented in the changelog when appropriate.

## Scope

This repository provides security-oriented guidance for AI coding assistants. It is not a substitute for a security assessment of a specific system, professional incident response, or compliance advice. Always validate generated commands and changes in your own environment before applying them.
