## [0.1.0] - 2026-09-09

### Added

- `secure-coding`: secure-by-default coding guidance, framework-aware references, and a code-review checklist
- `secure-docker`: hardened Dockerfile and Docker Compose guidance, multi-stage templates, and scanning commands
- `secure-terraform`: Terraform, state, secrets, cloud-control, scanning, and plan/apply guidance
- `secure-cicd`: GitHub Actions, GitLab CI, dependency pinning, SBOM, signing, and CI/CD hardening guidance
- `server-security-audit`: read-only server-audit workflow followed by validated remediation
- `security-audit-review`: workflow for evaluating automated audit reports before acting on findings
- French and English project documentation
- Linux/macOS and Windows installation scripts
- Automated validation for skill files
